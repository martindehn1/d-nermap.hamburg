# Marketing-Skills

Kuratierte Auswahl aus [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
(MIT, Copyright (c) 2025 Corey Haines — siehe `LICENSE-marketingskills`).

Nicht alle 49 Skills des Projekts sind hier, sondern nur die, die zu dieser
Seite passen. Weggelassen wurden u.a. die SaaS-/B2B-lastigen Skills
(`revops`, `paywalls`, `pricing`, `sales-enablement`, `directory-submissions`
— letzteres zielt auf Startup-Verzeichnisse wie Product Hunt und G2, nicht auf
lokale Branchenverzeichnisse).

## Was hier liegt

| Skill | Wofür |
|---|---|
| `product-marketing` | Basis-Kontext (Produkt, Zielgruppe, Positionierung). Legt `.agents/product-marketing.md` an, das alle anderen Skills zuerst lesen. **Zuerst ausführen.** |
| `seo-audit` | Technische Basics: canonical, `robots.txt`, `sitemap.xml`, Meta-Tags, Core Web Vitals |
| `programmatic-seo` | Viele Seiten aus Daten erzeugen — hier: eine Seite je Laden / Stadtteil / PLZ |
| `schema` | JSON-LD (`Restaurant`, `Review`, `ItemList`) für Sterne-Snippets in Google |
| `site-architecture` | URL-Struktur und interne Verlinkung für ebendiese Seiten |
| `ai-seo` | Zitiert werden in ChatGPT / Perplexity / AI Overviews |
| `content-strategy` | Themenplanung, z.B. Stadtteil-Guides |
| `social` | Instagram / TikTok / Reels — Content-Formate und Hooks |
| `copywriting` | Seitentexte |

## Update

    npx skills add coreyhaines31/marketingskills --skill <name>

oder direkt aus dem Upstream-Repo in `.claude/skills/<name>/` kopieren.
